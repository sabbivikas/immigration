# US migration visualization (modified fork)

This repository is a **fork and modification** of **[Track Migrations](https://trackmigrations.org/)** by Isabelle Reksopuro ([@isareksopuro](https://x.com/isareksopuro)). The original is a data journalism visualization that makes US immigration data tangible: a particle map (each dot ≈ hundreds of people, by month) plus editorial sections on crossings, origins, contributions, and context.

## What changed in this fork

Maintained by **Vikas Sabbi**. This pass (and current scope) focuses on **identity and attribution only**:

- Site metadata (title / description) in `app/layout.tsx`
- Footer attribution and fork labeling in `components/PageClient.tsx` and header labeling in `components/ui/Header.tsx`

**Not changed:** methodology copy's numeric claims, `scripts/normalize.py`, or map / particle logic.

## Tech stack

- **Next.js 16** + **React 19** + **TypeScript**
- **Tailwind CSS v4** for styling
- **d3-geo** + **topojson-client** for the US map projection
- **Canvas API** for particle rendering (two-layer architecture: settled + active)
- Data sourced from **CBP**, **Census ACS**, **USCIS**, and several research institutions (per upstream methodology)

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:3000`).

The app imports `data/particles.json` (generated by upstream tooling, typically `scripts/normalize.py`). If that file is missing, add it from the original project or generate it after placing raw inputs under `data/raw/` and running the Python pipeline documented in `scripts/normalize.py`.

```bash
npm run build   # production build
npm run start   # run production server after build
npm run lint    # eslint
```

## State settlement & contribution data (populated)

The scaffolding datasets are now populated from real sources (Sept 2026 pass):

- `data/immigrant-presence/`: AIC Map the Impact (ACS 2023 vintage) — foreign-born residents, derived non-citizen count, foreign-born labor force, STEM workers. `healthcareWorkers` stays null: no per-state count is published.
- `data/economic-contribution/`: AIC 2023 — taxes paid, spending power, entrepreneurs, undocumented-household taxes.
- `data/inflow-outflow/`: Census Vintage 2025 net international migration per state (July 2024 - July 2025, model-based estimate). IRS SOI and removals stay null.
- `data/sources/`: live source registry with `dataYear` vs `lastFetched` kept separate.

### Folder structure

- `data/immigrant-presence/`: ACS-derived “who lives here” metrics (foreign-born population, citizenship, workforce composition)
- `data/economic-contribution/`: AIC-derived contribution metrics (taxes, spending power, entrepreneurs, STEM/healthcare where provided)
- `data/inflow-outflow/`: net movement + inflow/outflow measures (Census NIM, IRS SOI, and enforcement outflow as separate definitions)
- `data/sources/`: a source registry with `lastFetched` placeholders

### Update strategy (future)

- **Census ACS API**: fetched via scripts; store **official `dataYear`** (vintage) per metric and **`lastFetched`** per source.
- **American Immigration Council**: ingest from stable downloads when available; otherwise store raw artifacts under `data/raw/` and normalize.
- **DHS/OHSS / ICE**: ingest annual yearbook + monthly enforcement tables; keep time units explicit.
- **Census Net International Migration**: treat as estimates; label uncertainty and never imply real-time precision.
- **IRS SOI migration**: treat as **tax-return universe** flows; label limitations.

Important: keep **official data year** (`dataYear`) separate from **site refresh** (`generatedAt`) and **retrieval date** (`lastFetched`).
